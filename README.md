# Parallel & Distributed Computing (PDC) – Semester Practice

This repository contains my **practice files, assignments, and mini-projects** completed during the **Parallel & Distributed Computing (PDC)** course for the semester.

The notebooks and scripts cover key PDC concepts, including **parallel computing, distributed computing, synchronization, and load balancing**, along with practical exercises.

---

- Practice exercises for Parallel Computing (multi-core processing)  
- Assignments and mini-projects on Distributed Computing (networked nodes)  
- Sample implementations for speedup, synchronization, and fault tolerance  
- Notes and reference scripts for understanding key concepts  

---

## 🛠 Tools & Technologies

- Python  
- Google Colab / Jupyter Notebooks  
- Multi-threading / Multiprocessing libraries  
- Simulation of distributed tasks (networked computing)
